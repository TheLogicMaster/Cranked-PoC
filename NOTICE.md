# Notices

## How this was made (AI use)

The patches in `patches/`, the scripts, the CI workflow and the documentation in this repository were written by
an AI system (Anthropic's Claude), working under the direction of Cranked's maintainer, who set the goals and
rules and reviewed the results. They have not been reviewed line by line.

Cranked's own contribution rules do not accept AI-generated code. This repository is therefore not a
contribution to Cranked and is not offered for merging into it. It is a separate, unsupported Proof of Concept;
Cranked is to be reimplemented from scratch, by people, using what was learned (written up in
[Cranked APIs](https://github.com/TheLogicMaster/Cranked-APIs)).

Statements in the code comments about how "the device" behaves come from analysis of the device's software
(OS 3.1.2). They have not been confirmed by running on a physical Playdate. Statements about "the Simulator" were
measured in the Playdate SDK 3.1.1 Simulator.

This repository contains no part of the Playdate SDK. To build, you supply your own copy of the SDK
(`--sdk`), and the build copies a few of its assets into your local build:

- The Playdate system fonts (Roobert). The SDK's README licenses the Playdate fonts under the Creative Commons
  Attribution 4.0 International license (CC BY 4.0). A build that includes them must carry an attribution; the one
  used here is "Playdate fonts by Panic Inc., licensed under CC BY 4.0
  (https://creativecommons.org/licenses/by/4.0/)".

  SDK outside programs made for the Playdate. A build that includes them is for your own use; do not distribute

Builds meant for distribution (the CI workflow's artifacts and the hosted web site) are made with
`SDK_ASSETS=fonts`, which embeds only the CC BY fonts (with the attribution above, shown in the front ends' about
text) and replaces the other SDK assets, and Cranked's own older copies of the crank indicator, keyboard images and
bounce sound, with plain stand-ins drawn by `scripts/make-standin-assets.py` (only their sizes and formats are taken
from the SDK). See README.md.
